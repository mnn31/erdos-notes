# Erdős problem notes

Partial results, exact small values and computations on open problems from [erdosproblems.com](https://www.erdosproblems.com), November 2026.

**How these were produced.** The arguments, computations and write-ups were found and written with Claude (Anthropic) agents. Each result below was checked by three independent AI referee passes (source, logic, novelty) and the computational ones were re-checked with independently written code. None of this is peer reviewed. "New as far as checked" means it was not found on the problem page, its forum thread, the Plasma AI and other public AI-contribution repositories, formal-conjectures, or a literature search; it does not mean it is certainly new. Corrections are welcome as issues.

Only part of the 675 result is checked in Lean: see [google-deepmind/formal-conjectures#8195](https://github.com/google-deepmind/formal-conjectures/pull/8195).
